### <a name="_qmphm5d6rvi3"></a>**Основное решение**

1. На каждой из ферм развернут агент, собирающий данные с датчиков и камер.
2. Роли отвечающие за оперативное управление фермой (ветеринар, механик, агноном) получают оперативные данные о состоянии ферм через агенты, работающие на каждой ферме.
3. Агенты собирают оперативные данные о состоянии ферм и передают их на центральный сервер. Если связи с центральным сервером нет, аненты сохраняют полученные данные и передают их на сервер после появления связи.
4. Для подготовки отчетов исползуется существуется BI-система.
5. Уведомления для сотрудников, работающих через агенты, обеспечивают агенты.
6. Уведомления для сотрудников, работающих в системах управления предприятием и других, обеспечивает подсистема уведомлений.

### <a name="_bjrr7veeh80c"></a>**Альтернативное решение**

1. Альтернативное решение совпадает с основным, за исключением замены центрального сервера на сервер облачных вычислений.
2. В случае альтернативного решения сервер облачных вычислений включает в себя функционал подготовки отчетов, таким образом отдельная BI-система не требуется.
3. Сервер облачных вычислений не забирает ERP-систему, оперативное управление на уровне предприятия продолжает базироваться на решениях 1С.

**Недостатки, ограничения, риски**

1. Основное решение достаточно для решения поставленных Заказчиком задач, однако тиражирование данного решение сложнее и дороже.
2. Альтернативное решение позволяет тиражировать решение на других фермах без созданий новой инсталляции центрального сервера.
3. Тем не менее создание сервера облачных вычислений сложнее и дороже, в том числе за счет необходимости поддержки совместимости с разными устройствами.
4. Сервер облачных вычислений создает задел для дальнейшего развития его как SaaS решения.
